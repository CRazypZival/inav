关键参数（英文名词）
CTRL2_G 寄存器（陀螺仪控制）
FS_G [3:0] - Gyro Full Scale Selection
具体的位位置（bit position）：CTRL6 (15h) 寄存器的 bit7~bit4
各个值对应的量程：
0000：±125 dps（默认）
0001：±250 dps
0010：±500 dps
0011：±1000 dps
0100：±2000 dps
1100：±4000 dps（注：选择此量程时需禁用陀螺仪 OIS 链）
其他值：保留
CTRL1_XL 寄存器（加速度计控制）
FS_XL [1:0] - Accelerometer Full Scale Selection
具体的位位置：CTRL8 (17h) 寄存器的 bit1~bit0
各个值对应的量程：
00：±2 g
01：±4 g
10：±8 g
11：±16 g
CTRL7_G 寄存器（陀螺仪高级控制）
G_HM_MODE - Gyro High Performance Mode：LSM6DSV16X 中无此位，陀螺仪高性能模式通过 CTRL2 (11h) 寄存器的 OP_MODE_G [2:0] 位配置（000 对应高性能模式）
HP_EN_G - Gyro High Pass Filter Enable：LSM6DSV16X 中无此位，陀螺仪高通滤波功能通过 CTRL9 (18h) 寄存器的 HP_SLOPE_XL_EN 位间接关联（仅针对加速度计斜率滤波 / 高通滤波选择）
HPM_G [1:0] - Gyro High Pass Filter Mode Selection：LSM6DSV16X 中无此位，陀螺仪滤波配置通过 CTRL6 (15h) 寄存器的 LPF1_G_BW_[2:0] 位设置低通滤波带宽
CTRL9_XL 寄存器（加速度计接口控制）
I2C_I3C_DISABLE - 禁用 I2C/I3C 接口
具体的位位置：IF_CFG (03h) 寄存器的 bit0
值说明：
0：SPI、I2C 和 MIPI I3C® 接口均启用（默认）
1：I2C 和 MIPI I3C® 接口禁用
CTRL3_C 寄存器（通用控制）
IF_INC - Auto-increment address during burst reads
具体位置：CTRL3 (12h) 寄存器的 bit3
值说明：0 禁用，1 启用（默认）
SIM - SPI Serial Interface Mode
具体位置：IF_CFG (03h) 寄存器的 bit1
值说明：0 4 线接口（默认），1 3 线接口
PP_OD - Push-Pull / Open Drain
具体位置：IF_CFG (03h) 寄存器的 bit3
值说明：0 推挽模式（默认），1 开漏模式
H_LACTIVE - Interrupt active level
具体位置：IF_CFG (03h) 寄存器的 bit4
值说明：0 中断输出高电平有效（默认），1 低电平有效
CTRL4_C 寄存器
DRDY_MASK - Data Ready Mask
具体位置：CTRL4 (13h) 寄存器的 bit6
值说明：0 禁用（默认），1 屏蔽数据就绪信号直至滤波器稳定
I2C_DISABLE - I2C Interface Disable：无此位，I2C 接口禁用通过 IF_CFG (03h) 寄存器的 I2C_I3C_DISABLE 位控制
LPF1_SEL_G - Gyro LPF1 Selection：无此位，陀螺仪 LPF1 选择通过 CTRL6 (15h) 寄存器的 LPF1_G_BW_[2:0] 位配置
CTRL6_C 寄存器
XL_HM_MODE - Accelerometer High Performance Mode：LSM6DSV16X 无此位，加速度计高性能模式通过 CTRL1 (10h) 寄存器的 OP_MODE_XL_[2:0] 位配置（000 对应高性能模式）
FTYPE [2:0] - Gyro LPF1 Cutoff Frequency Selection：无此位，陀螺仪 LPF1 截止频率通过 CTRL6 (15h) 寄存器的 LPF1_G_BW_[2:0] 位选择，具体带宽需结合陀螺仪 ODR 确定
其他
ODR（Output Data Rate）的具体值和位位置：
陀螺仪 ODR：CTRL2 (11h) 寄存器的 ODR_G [3:0] 位（bit7~bit4）
取值对应的 ODR：
0000：掉电（默认）
0010：7.5 Hz
0011：15 Hz
0100：30 Hz
0101：60 Hz
0110：120 Hz
0111：240 Hz
1000：480 Hz
1001：960 Hz
1010：1.92 kHz
1011：3.84 kHz
1100：7.68 kHz
其他值：保留
加速度计 ODR：CTRL1 (10h) 寄存器的 ODR_XL_[3:0] 位（bit7~bit4）
取值对应的 ODR：
0000：掉电（默认）
0001：1.875 Hz（仅低功耗模式）
0010：7.5 Hz（高性能、正常模式）
0011：15 Hz（低功耗、高性能、正常模式）
0100：30 Hz（低功耗、高性能、正常模式）
0101：60 Hz（低功耗、高性能、正常模式）
0110：120 Hz（低功耗、高性能、正常模式）
0111：240 Hz（低功耗、高性能、正常模式）
1000：480 Hz（高性能、正常模式）
1001：960 Hz（高性能、正常模式）
1010：1.92 kHz（高性能、正常模式）
1011：3.84 kHz（仅高性能模式）
1100：7.68 kHz（仅高性能模式）
其他值：保留
特殊的初始化序列或时序要求：
启用模拟集线器 / Qvar 功能前，需将加速度计和陀螺仪配置为掉电模式
HAODR 模式需在设备掉电时启用 / 禁用，且启用后加速度计和陀螺仪需同时配置为 HAODR 模式
ODR 触发模式需在设备掉电时启用 / 禁用，且启用后加速度计和陀螺仪需配置相同 ODR
I3C 接口使用时，主机需先发送广播地址 7'h7E/W 以关闭防尖峰滤波器
寄存器写入时，需确保 IF_INC 位配置正确（默认启用），以支持突发读取时地址自动递增
电源供应需添加 100 nF 去耦电容，且靠近设备电源引脚放置
